# ADR-002: Границы доверия и токены

**Статус:** принято. Используется один HMAC SHA-256 ключ
длиной минимум 32 байта (`JWT_SECRET`). Токен с claim `role=USER|ADMIN`
живёт 3600 секунд. Booking выдаёт токен, Booking и Catalog валидируют его
**самостоятельно** как OAuth2 Resource Server. Gateway только предварительно
отфильтровывает доступ и проксирует оригинальный `Authorization`.

`/internal/**` намеренно отсутствует в публичном RouteLocator. Прямые
межсервисные вызовы требуют отдельный заголовок `X-Internal-Key`; Gateway
удаляет такой заголовок от входящих клиентов. 

Фильтр корреляции принимает только короткие безопасные идентификаторы и добавляет
`X-Correlation-Id` в ответ/логи. В саге дополнительно логируется `bookingId`.
